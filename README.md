## About Me

I'm a Systems Developer with experience in developing and maintaining ERP systems, primarily focused on backend development using PHP, Laravel, and PostgreSQL.

My work involves implementing business rules, developing and integrating REST APIs, maintaining existing systems, fixing bugs, and reviewing code. I also help organize tasks and guide junior developers, contributing to code quality and continuous improvement.

I'm currently pursuing a degree in Software Engineering and continuously developing my skills through professional experience, personal projects, and independent study.

Outside software development, I'm interested in finance and financial markets.
